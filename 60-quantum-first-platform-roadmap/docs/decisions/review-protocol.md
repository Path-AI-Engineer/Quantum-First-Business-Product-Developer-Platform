# Final review protocol

The frozen review uses 437 registered cases and three reconciled audiences. A reviewer must be able to reconstruct the source revision, assumptions, formulas, owners, dependencies, cost range, gates, signals, state transition, dissent, and checksum for every material decision.

The candidate status is `technical_candidate_unapproved`. Approval requires a named authorized reviewer and an external decision record; the repository does not self-approve. Until that occurs, the transition to Plan 11 remains blocked by governance even when all technical gates are green.
