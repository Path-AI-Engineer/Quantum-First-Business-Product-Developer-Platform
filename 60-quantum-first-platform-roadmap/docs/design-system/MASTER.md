# Quantum-First Strategy Control Tower design system

- Pattern: enterprise decision gateway with persistent view navigation.
- Style: OLED dark, high contrast, minimal glow, evidence-first density.
- Palette: background `#050510`, text `#E8E9FF`, cyan `#42E8E0`, violet `#8D78FF`, magenta `#FF52CF`.
- Type: editorial serif for strategic headings; neutral sans-serif for operations.
- Interaction: visible focus, 150–300 ms transitions, reduced-motion support, no emoji icons, 375/768/1024/1440 responsive checks.
- Avoid generic marketing cards, decorative dashboards without decisions, hidden uncertainty, and color-only state meaning.
