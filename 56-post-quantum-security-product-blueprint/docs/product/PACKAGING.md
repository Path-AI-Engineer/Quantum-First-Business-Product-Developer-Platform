# Packaging and pricing — unvalidated hypotheses

| Package | Hypothesized unit of value | Inclusions | Exclusions |
| --- | --- | --- | --- |
| Readiness Assessment | One scoped assessment | Offline inventory, findings, reports | Continuous monitoring |
| Migration Portfolio | Assets in planned waves | Dependencies, owners, evidence acceptance | Migration execution |
| Continuous Crypto Posture | Organization-year and scoped sources | Periodic refresh, standards watch | Certification or 24/7 SOC |
| Enterprise/Managed Program | Program scope plus services | Governance, integrations, support | Automatic key/protocol changes |

Test pricing by assessment, asset/scope and organization/year with customer
interviews. Professional services are priced separately from software. No
price, willingness-to-pay, market share, conversion or ROI is represented as
measured. Candidate experiments: five buyer interviews per ICP segment, a
fixed-scope pilot quote, and a value/cost sensitivity table before any list
price. Buyer objections to test: incomplete inventory, standards drift,
false positives, data residency, vendor lock-in, and responsibility for
cryptographic decisions. “Quantum-safe” is not a package promise.
