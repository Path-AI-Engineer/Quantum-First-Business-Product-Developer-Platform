# Positioning and alternatives — hypothesis, not market validation

The wedge is the evidence-to-migration handoff: the product normalizes
heterogeneous observations, preserves uncertainty, connects owners and
dependencies, and produces reconciled reports. It is not a scanner and does
not replace cryptographic expertise.

| Category | Integrate / compete / partner | Boundary |
| --- | --- | --- |
| Static code scanner | Integrate through SARIF fixture | Do not claim complete runtime inventory |
| CBOM/SBOM tool | Integrate through offline JSON fixtures | Preserve unknown crypto properties |
| CA/PKI platform | Partner / ingest metadata | Never rotate keys or alter certificates |
| GRC platform | Integrate report and exception workflow | Do not certify compliance |
| Consultancy | Partner on verification and migration | Keep human decisions explicit |

Anti-features: active scanning, automatic remediation, vulnerability
exploitation, quantum breach timing, single-number “quantum-safe” score, and
silent suppression of contradictory evidence. Build/buy choice: use existing
inventory outputs; build only the normalized evidence and migration decision
layer. This position requires customer interviews before investment.
