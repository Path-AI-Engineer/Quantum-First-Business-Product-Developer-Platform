# Commercial model — hypotheses only

## Packages

| Package | Unit | Hypothesis |
|---|---|---|
| Assessment | bounded use case | fixed fee after data-readiness screen |
| Pilot | eight-week shadow decision | milestone fee with explicit termination |
| Managed review | decision volume | subscription plus reviewed usage band |
| Platform adapter | integration boundary | implementation fee; not included in this candidate |

The value model exposes improvement, adoption, decision volume, integration cost, annual operating cost, risk adjustment, and time horizon. It returns annualized value and payback ranges, break-even adoption, cost per decision, sensitivity, evidence needs, and a no-go flag.

No point ROI is published. Pricing, delivery capacity, margin, and success components remain experiments requiring finance and procurement review.
