# Quantum-First Venture Evidence Room — design system

Decision support with an editorial hierarchy, not an aspirational marketing page.
UI UX Pro Max informed the data-dense layout, visible focus, semantic tokens and
responsive states. No paid component retrieval or generated illustration needed.

Canvas #f6f7f2, paper white, text #223d35, secondary #617168, action #1a6952,
border #dde5dd, uncertain state #865216 on warm amber. Georgia for thesis
headings; local Arial/Helvetica for dense research. No remote font requests.

One fixed research sidebar on desktop; explicit labeled collapsible menu on
mobile. Scenario tables scroll within their own region, never the page.
No saturation gradient, decorative chart, fake avatar or fabricated KPI.
Ranges have textual accessible labels; confidence and status use words plus color.

Required states: loading, retryable server failure, empty search, invalid input,
pending calculations, read-only candidate download and approval pending.
Respect reduced motion and keyboard focus; provide a skip-to-evidence link.
The actual Playwright captures live in reports/visual, never mocked screenshots.
